# 双边自由挂单规则

依据2026-11-18最新决策，本文件取代2026-11-17的三档价格偏离自动成交、产品团队审单和大偏离拒绝方案。此前示例阈值0.001、0.005、1不再作为当前交易规则。

## 买卖双方自主挂单

买卖双方可分别输入价格和面值，独立发布挂单。系统保存方向、机构、产品、价格、金额、购买日、退出日、创建时间、超时时间和历史记录。相同价格出现时仍保持挂单中，不自动撮合，也不由产品团队代替交易双方决定成交。

成员可买入，并仅在有可卖持仓时卖出。卖方库存挂单需要明确的卖方交易员角色；产品团队及运营账号不自动获得此权利。Group保留卖方挂单页，运营仅监控挂单和设置超时参数。

双方如何选择对手方、确认一致的成交价格/数量、进行双边确认和后续结算，仍需业务确认。当前不虚构成交确认或资金划转，不生成自动成交持仓。

## 价格刷新

每5分钟刷新价格信息和公开挂单展示，供双方参考。参考报价显示自身来源时间；页面刷新时间不能冒充新市场报价时间。没有实时行情接口时只重新读取已有价格，不随机生成行情。改价由本人发起，不由刷新任务自动修改挂单价格。

## 超时撤销

挂单有效期可配置，当前使用120分钟作为演示值，最终采用2小时或其他时长待确认。创建时保存到期时间；修改设置只影响新挂单，改价暂不延长原有效期，最终续期口径待确认。

到期未成交自动改为超时已撤销，释放关联容量、可卖库存和实际存在的资金占用；不虚构退款。重开页面、提交、改价、撤单及定时检查都校验超时；已到期不可通过改价恢复，需重新挂单。

未来购买首先锁定容量的确认继续保留。定金、全额扣款或资金冻结方式仍待确认，当前原型不实际冻结或扣收挂单资金。库存与容量采用现有Series总量校验，逐日窗口容量以及跨客户并发需服务端实现。

## 历史与技术边界

旧偏离机制的未成交等待订单不再进入自动成交或产品团队审批，应撤销并重新挂单；已有成交历史保留。旧自动成交逻辑在新模块加载失败时也不得回退启用。

当前为静态原型：定时器与重新打开后的到期补偿已实现；浏览器关闭期间按实际到期时点主动执行、权威价格刷新、跨端订单存储、原子资金释放和成交结算，需要后台任务与接口接入。

沿用现有金额及手续费展示，买卖两侧手续费分配和正式计费时点待业务确认；本次不另行改变既有挂单输入字段、产品规格与计算明细布局。
