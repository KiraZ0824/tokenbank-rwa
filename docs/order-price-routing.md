# 挂单价格偏离处理需求

依据：2026-11-17用户最新确认。该确认取代此前MVP清单中“成员只能接受卖方报价、不允许自行出价”的范围限制。

成员可填写挂单价格，系统使用该价格计算挂单金额。提交时保存挂单价、参考报价、报价时间、面值、购买日期、退出日期及当时规则版本。

## 三种处理路径

1. 在允许偏离范围内：自动成交，无需产品团队人工审核。
2. 超出自动成交范围，但属于较小偏离：转产品团队审核。通过后进入成交或后续结算；拒绝则挂单失败。
3. 偏离较大、超过审核允许范围：直接拒绝挂单，不生成持仓或成交资金记录。

根据用户后续演示要求，默认使用临时绝对价差规则：偏离≤0.001自动成交；0.001<偏离<1进入审核；偏离≥1自动拒绝。0.005进入审核。0.001至0.005之间暂按审核处理，最终区间待签认。规则管理保留后台配置，但成员端不展示阈值、权限归属、待配置或资金方案等产品实现信息。

当前原型使用既有价格基数计算“面值×挂单价格＋当前每笔交易费20”，不在此次修改中擅自采用尚有冲突的MVP新定价公式。实时试算和提交确认使用同一挂单价格。

## 产品团队及权限

Bison Group和TokenBank运营端均保留挂单价格审核及规则入口，共享订单ID、状态和审核轨迹，不增加两次审批。实际使用端及最终权限归属待确认；当前延续原型审核角色，规则维护仅限原型管理员。

产品发行审核、挂单价格审核和IT审核是不同任务。IT审核保留在TokenBank运营端，不能替代挂单价格审核。

## 容量和资金

未拒绝挂单须校验并占用容量。待审核、待规则配置和未来购买订单不生成已成交持仓。拒绝、撤销或结算失败释放占用；重复提交与重复审核不得重复记账。

未来购买首先锁定容量；资金收取定金还是扣收全款待确认。价格检查通过或人工审核通过，不代表未来购买立即扣款成交，状态为“容量已锁定、资金规则待确认”。当前原型按既有Series可售总量校验，尚未实现逐日容量日历。

当日自动或审核后成交使用挂单价格，不以参考报价替代。成交时复核成员权限、产品状态和可用余额。真实资金原子交割、权威报价锁定/过期校验、逐日库存、后台幂等及审计接口仍需服务端集成。

## 原型验收

无需预先配置：按用户示例的临时规则展示自动成交、挂单中或失败。
配置测试阈值后：覆盖自动成交下界/上界、人工审核区间及上界、偏离过大拒绝。
人工审核：通过只生成一次持仓，拒绝须填写原因；另一端不得重复处理。
未来购买：容量锁定，余额不扣减，资金规则保持待确认。
用户价格：试算、确认金额、订单记录和成交价格一致。

成员端只展示挂单价格、参考报价、面值、金额、购买日期及处理结果。进入产品团队审核的订单显示“挂单中”；大偏离明确提示“挂单失败：价格偏离较大，系统已拒绝”。后台未决事项仅保留在需求和管理端。
